# 🔐 FIV (Fandeta Is Vulnerable)
*# Simulating web vulnerabilities for ethical hacking education.*  


*An open-source project to learn web vulnerabilities through articles and hands-on labs.* 
**Live Demo**: 🌐 [fandeta.github.io/fiv](https://fandeta.github.io/fiv)  

---

## 🚀 Overview

FIV teaches web security vulnerabilities through **structured articles** and **interactive labs**. Designed for beginners, developers, and ethical hackers, it combines theory with safe, practical exploitation scenarios.

### Key Features:
- **📚 Articles**: Deep dives into vulnerabilities (XSS, SQLi, CSRF, etc.) with real-world examples.
- **🔬 Labs**: Safe, Docker-based environments to practice exploits (Coming Soon!).
- **🛠️ Code-Driven Learning**: Highlighted code snippets using `highlight.js`.
- **🧠 6-Step Framework**: Each article covers *what, why, risks, exploits, fixes*, and *resources*.

---

## 🛠️ Tech Stack
- **Frontend**: HTML, CSS, JavaScript, ReactJS
- **Backend**: PHP, MySQL (Lab Integration)  
- **Deployment**: GitHub Pages (Current), Docker (Labs)  
- **Tools**: [highlight.js](https://highlightjs.org/) (code syntax), [scrollrevealjs](https://scrollrevealjs.org/) (for animating elements)
